# Project Bust v2 — çene–boyun çakışma düzeltmesi

Eğme servoları boynun ARKASINA ve yatık, çene servosu kafatası yanında (kondil arkası kaldıraç), döner tabla r=62 mm. Canlı boşluk ölçümü + <5 mm'de eğme kilidi (firmware kuralının sim karşılığı). Ölçüm: nötr ~26 mm, çene kapalı −25°'ye kadar serbest, çene açık −9.5°'de kilit.
