# Project Bust v1 — anatomik kafatası (konsept)

Kaba three.js konsepti, CAD değil. İnsan kafatası oranları (boy 19, en 14.5 cm; gözler baş yüksekliğinin ortasında), göz çukurları, elmacık kemeri, burun açıklığı, V daralan alt çene. Hareket: sakkad 2.2·A+21 ms, kırpma 80/200 ms, baş >20°'de devreye girer + VOR.
Bilinen sorun: eğme servoları/pistonlar boynun önünde → alt çene baş eğilince bunların içinden geçiyor (v2'de düzeltildi).
